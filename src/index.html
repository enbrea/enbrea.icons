Enbrea Icons Collection

Die Enbrea Icons Collection enthält alle Icons, die im Enbrea-Projekt verwendet werden. Wir haben Icons aus dem Google Material Design Icons Project genommen und sie mit unseren eigenen Icons kombiniert. Die Enbrea Icons Collection ist Open Source und unter der Apache License Version 2.0 lizenziert.
